# Reference implementation

The Theuth framework is designed to be independent of any single implementation. It defines methodological principles, knowledge structures, workflows, and reusable templates; an implementation applies and adapts them using its own repository, tools, provider, and operational controls.

The first planned reference implementation will apply Theuth in the **TheuthMT** personal working-memory orientation. It will demonstrate one practical way to organize a personal knowledge layer, including conversation sources, project context, decisions, and retrieval. The implementation will be maintained separately from this framework repository.

TheuthMT names the personal orientation; it is not the implementation itself. The reference implementation is a concrete project that applies Theuth and may change its technical choices without changing the framework. Other implementations may use different tools or apply the shared **TheuthMTC** orientation, or combine personal and shared needs where appropriate.

A reference implementation is illustrative, not mandatory. It can help test the framework, reveal gaps, and provide a working example, but it does not define the only valid architecture or require other users to adopt its choices. Any implementation should document the adaptations it makes and observe the authorization, privacy, retention, and access rules that apply to its sources and users.

## Relationship

- **Theuth:** the portable methodological framework.
- **TheuthMT / TheuthMTC:** recommended personal and shared orientations for applying the framework.
- **Reference implementation:** a separate project demonstrating one application of Theuth, initially in the TheuthMT orientation.

# Implementación de referencia

El framework Theuth está diseñado para ser independiente de una implementación concreta. Define principios metodológicos, estructuras de conocimiento, flujos y plantillas reutilizables; cada implementación los aplica y adapta con su propio repositorio, herramientas, proveedor y controles operativos.

La primera implementación de referencia prevista aplicará Theuth en la orientación de memoria de trabajo personal **TheuthMT**. Mostrará una forma práctica de organizar una capa personal de conocimiento, incluidas fuentes de conversación, contexto de proyectos, decisiones y retrieval. La implementación se mantendrá en un repositorio separado del framework.

TheuthMT nombra la orientación personal; no es la implementación en sí. La implementación de referencia será un proyecto concreto que aplica Theuth y podrá cambiar sus decisiones técnicas sin cambiar el framework. Otras implementaciones podrán utilizar herramientas distintas, aplicar la orientación compartida **TheuthMTC** o combinar necesidades personales y compartidas cuando corresponda.

Una implementación de referencia es ilustrativa, no obligatoria. Puede ayudar a probar el framework, detectar vacíos y ofrecer un ejemplo funcional, pero no define la única arquitectura válida ni exige que otros usuarios adopten sus decisiones. Cada implementación debe documentar sus adaptaciones y respetar las reglas de autorización, privacidad, retención y acceso aplicables a sus fuentes y usuarios.

## Relación

- **Theuth:** el framework metodológico portable.
- **TheuthMT / TheuthMTC:** orientaciones recomendadas de aplicación personal y compartida.
- **Implementación de referencia:** un proyecto separado que demuestra una aplicación de Theuth, inicialmente en la orientación TheuthMT.
