# Theuth v0.1.0

The first documented release of Theuth, an adaptable methodological framework for working knowledge connected to one or more LLMs.

## Included

- Core principles for provenance, evidence, revision, privacy, and portable records.
- A knowledge model for sources, claims, decisions, and project context.
- Flexible personal and shared orientations: TheuthMT and TheuthMTC.
- Guidance for conversation sources, retrieval, correction, revision, privacy, retention, and removal.
- Reusable templates, examples, and manual retrieval evaluation cases.
- A clear separation between the framework and its planned reference implementation.

## Scope

Theuth v0.1.0 is a documented proposal, not a closed standard or a complete software implementation. It does not prescribe a provider, database, interface, indexing method, or shared deployment controls. Implementations should adapt the framework to their goals, sources, permissions, and operating context.

See [the release scope](release-scope.md) and [the reference implementation note](reference-implementation.md).

# Theuth v0.1.0

Primera versión documentada de Theuth, un framework metodológico adaptable para el conocimiento de trabajo vinculado al uso de uno o varios LLM.

## Contenido

- Principios básicos sobre procedencia, evidencia, revisión, privacidad y registros portables.
- Un modelo de conocimiento para fuentes, afirmaciones, decisiones y contexto de proyecto.
- Orientaciones personales y compartidas flexibles: TheuthMT y TheuthMTC.
- Guías para fuentes de conversación, retrieval, corrección, revisión, privacidad, retención y retirada.
- Plantillas reutilizables, ejemplos y casos manuales de evaluación de retrieval.
- Una separación explícita entre el framework y su futura implementación de referencia.

## Alcance

Theuth v0.1.0 es una propuesta documentada, no un estándar cerrado ni una implementación completa de software. No prescribe proveedor, base de datos, interfaz, método de indexación ni controles para despliegues compartidos. Las implementaciones deben adaptar el framework a sus objetivos, fuentes, permisos y contexto operativo.

Consulta [el alcance de la versión](release-scope.md) y [la nota sobre implementación de referencia](reference-implementation.md).
