# Theuth v0.1.0

## Release scope

Theuth v0.1.0 is an initial, adaptable methodological framework for building working knowledge layers connected to the use of one or more LLMs. It focuses on preserving useful context, provenance, and work status so that individuals or teams can retrieve relevant material and continue their work, including when changing providers.

This release includes:

- Core principles for provenance, evidence, revision, privacy, and portable records.
- A knowledge model for sources, claims, decisions, and project context.
- Recommended personal and shared usage profiles: TheuthMT and TheuthMTC.
- Guidance for conversation sources, retrieval, correction, revision, privacy, retention, and removal.
- Reusable templates and example cases, including manual retrieval evaluation cases.

TheuthMT and TheuthMTC are flexible orientations for applying the framework. They are not separate products, mandatory architectures, or complete implementations. The source types and controls used by an implementation depend on its purpose and permissions.

## What this release does not define

This release does not prescribe a software product, interface, database, indexing method, LLM provider, or automated workflow. It does not fully specify organizational governance, identity and access control, or operational safeguards for shared deployments. These choices must be defined and validated for each implementation and its context.

Theuth v0.1.0 is a documented proposal, not a closed standard or a claim that every workflow has been validated in production. The framework can evolve through implementation experience, retrieval evaluations, and revisions to its documentation.

## Versioning

The version identifies the state of this framework documentation. An implementation may use Theuth v0.1.0 while making and documenting its own technical and operational choices. Changes to this repository will be described in later releases.

# Theuth v0.1.0

## Alcance de la versión

Theuth v0.1.0 es un framework metodológico inicial y adaptable para construir capas de conocimiento de trabajo vinculadas al uso de uno o varios LLM. Se centra en conservar contexto útil, procedencia y estado de trabajo para que personas o equipos puedan recuperar material pertinente y continuar su trabajo, incluso al cambiar de proveedor.

Esta versión incluye:

- Principios básicos sobre procedencia, evidencia, revisión, privacidad y registros portables.
- Un modelo de conocimiento para sources, claims, decisions y contexto de proyecto.
- Perfiles de uso personal y compartido recomendados: TheuthMT y TheuthMTC.
- Guías para fuentes de conversación, retrieval, corrección, revisión, privacidad, retención y retirada.
- Plantillas reutilizables y casos de ejemplo, incluidos casos manuales de evaluación de retrieval.

TheuthMT y TheuthMTC son orientaciones flexibles para aplicar el framework. No son productos separados, arquitecturas obligatorias ni implementaciones completas. Los tipos de fuentes y los controles de una implementación dependen de su objetivo y de las autorizaciones aplicables.

## Qué no define esta versión

Esta versión no prescribe un producto de software, interfaz, base de datos, método de indexación, proveedor de LLM ni flujo automatizado. Tampoco especifica por completo la gobernanza organizativa, la identidad y el control de acceso ni las salvaguardas operativas de despliegues compartidos. Estas decisiones deben definirse y validarse para cada implementación y su contexto.

Theuth v0.1.0 es una propuesta documentada, no un estándar cerrado ni una afirmación de que todos los flujos se hayan validado en producción. El framework podrá evolucionar a partir de la experiencia de implementación, las evaluaciones de retrieval y las revisiones de su documentación.

## Versionado

La versión identifica el estado de la documentación del framework. Una implementación puede utilizar Theuth v0.1.0 y documentar por separado sus propias decisiones técnicas y operativas. Los cambios en este repositorio se describirán en versiones posteriores.
