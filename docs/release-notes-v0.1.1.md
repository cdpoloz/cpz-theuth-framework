# Theuth v0.1.1 — Contextual applicability and documentation

Documentation-focused evolution of the initial Theuth methodological framework.

## Changes since v0.1.0

- Added an AI-assisted getting-started guide.
- Clarified management of externally named original files through separate identifier registries, with optional hashes for verifying captured versions.
- Introduced a principle for checking whether retrieved knowledge fits a new intended use.
- Extended retrieval guidance to distinguish provenance, contextual applicability, and independently tested results.
- Documented conditions, limitations, and evidence for reusable artifacts.
- Added a bilingual contextual-application proposal, including a practical evaluation scenario and its limitations.
- Added Greg Isenberg's *VIBE MANUFACTURING IS HERE* to related work, with clear distinction from an academically validated framework.

## Status

The new contextual-application guidance is a **proposal awaiting empirical evaluation**. This release does not certify its effectiveness or introduce mandatory agents, tools, databases, or manufacturing procedures.

See the [v0.1.1 scope](release-scope-v0.1.1.md), [contextual application proposal](../methodology/contextual-application-proposal.md), and [original v0.1.0 notes](release-notes-v0.1.0.md).

# Theuth v0.1.1 — Aplicabilidad contextual y documentación

Evolución principalmente documental del framework metodológico inicial de Theuth.

## Cambios desde v0.1.0

- Añadida una guía de inicio asistido por IA.
- Aclarada la gestión de originales con nombres externos mediante registros de correspondencia separados, con hashes opcionales para verificar versiones capturadas.
- Introducido un principio para comprobar si el conocimiento recuperado se adecua a un uso nuevo.
- Ampliada la guía de recuperación para distinguir procedencia, aplicabilidad contextual y resultados comprobados independientemente.
- Documentadas condiciones, límites y evidencias de artefactos reutilizables.
- Añadida una propuesta bilingüe de aplicación contextual, con escenario de evaluación y sus limitaciones.
- Incorporado *VIBE MANUFACTURING IS HERE*, de Greg Isenberg, en trabajos relacionados, diferenciándolo de un framework validado académicamente.

## Estado

La nueva orientación sobre aplicación contextual es una **propuesta pendiente de evaluación empírica**. Esta versión no certifica su eficacia ni exige agentes, herramientas, bases de datos o procedimientos de fabricación.

Véase [el alcance de v0.1.1](release-scope-v0.1.1.md), [la propuesta de aplicación contextual](../methodology/contextual-application-proposal.md) y [las notas originales de v0.1.0](release-notes-v0.1.0.md).
