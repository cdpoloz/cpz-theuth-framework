# Initial design snapshot of Theuth

- **ID:** snapshot-2026-09-29-initial-design
- **Cutoff date:** 2026-09-29
- **Project:** [Theuth](../project.md)
- **Checkpoint reason:** preserve the first methodological proposal as a point of comparison
- **Scope:** purpose, structure, and initial foundation of the framework

## State on this date

Theuth is a methodological framework for designing persistent, searchable, and maintainable personal knowledge layers. The repository separates methodology, templates, and examples. The personal implementation will be independent and will contain the canonical records.

## Decisions active at that time

- [Adopt the name Theuth](../decisions/2026-09-26-project-name.md).
- [Separate the framework from its personal implementation](../decisions/2026-09-23-separate-framework-and-implementation.md).
- [Adopt a hybrid methodological foundation](../decisions/2026-09-23-methodological-foundation.md).
- [Organize the repository into methodology, templates, and examples](../decisions/2026-09-23-repository-structure.md).

## Traceable evidence

The [methodological claim record](../claims/2026-09-23-hybrid-approach.md) links to a [design conversation](../sources/2026-09-23-methodological-design-discussion.md). The source record states that it is a reconstruction and that the original conversation is not archived in this repository.

## Relevant milestones

This is the first checkpoint in the example case.

## Open items and questions

- Validate the templates through a complete walkthrough.
- Confirm the example records against the original history before using them as canonical sources.
- Test whether a new person can create an instance by following the guide.
