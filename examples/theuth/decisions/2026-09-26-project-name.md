# Decision: adopt the name Theuth

- **ID:** decision-2026-09-26-project-name
- **Status:** active
- **Date:** 2026-09-26
- **Project:** [Theuth](../project.md)

## Context

The provisional name “Second Brain” could be confused with an existing, widely used product or category. A distinctive name was sought that connected with the project’s purpose without describing it generically.

## Decision

Adopt **Theuth** as the framework’s name. The repository was later renamed to \`cpz-theuth-framework\` (2026-09-29).

## Reasons and evidence

The name refers to Theuth, a figure in Plato’s *Phaedrus* associated with the invention of writing. In the dialogue, writing supports memory but does not replace understanding. This tension represents the idea of external memory that helps people think and consult without being confused with knowledge itself.

The choice appears in the project design conversation of 2026-09-26. This record summarizes the reason given by its author; it does not document an exhaustive search of trademarks, domains, or commercial names.

## Alternatives considered

- **Second Brain:** a descriptive name already in wide use.
- **Cerebrate:** considered, but ultimately rejected in favor of Theuth.

## Consequences and conditions

The framework is named Theuth. The personal implementation will have an independent name and repository; this record does not settle that specific choice.

## Review

- Review if a decision is made to rename the framework or if a practical reason makes Theuth difficult to use.
- Replaced decision: none.
