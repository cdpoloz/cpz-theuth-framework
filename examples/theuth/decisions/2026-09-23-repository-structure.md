# Decision: separate methodology, templates, and examples

- **ID:** decision-2026-09-23-repository-structure
- **Status:** active
- **Date:** 2026-09-23
- **Project:** [Theuth](../project.md)

## Context

The framework repository needed a clear structure distinguishing the method’s rules from reusable materials and demonstrations.

## Decision

Organize the repository into three main areas:

- \`methodology/\` for principles and procedures;
- \`templates/\` for formats people can copy and adapt;
- \`examples/\` for showing how to apply the method.

The repository was initially created as \`cpz-second-brain-framework\` and later renamed to \`cpz-theuth-framework\`.

## Reasons and evidence

In the conversation on 2026-09-23, the author confirmed creating the repository with these three folders and a README. The separation makes the difference visible between explaining a rule, offering a template, and showing an applied case.

## Alternatives considered

No formal comparison with other structures is recorded. This organization was adopted as a simple starting point.

## Consequences and conditions

Examples should be fictional, anonymized, or explicitly identified as authorized real cases. The structure may be expanded if experiments reveal a stable need.

## Review

- Review if new content types appear that do not reasonably fit these three areas.
- Replaced decision: none.

# Decisión: separar metodología, plantillas y ejemplos

- **ID:** decision-2026-09-23-repository-structure
- **Estado:** active
- **Fecha:** 2026-09-23
- **Proyecto:** [Theuth](../project.md)

## Contexto

Se necesitaba iniciar el repositorio del framework con una estructura clara que distinguiera las reglas del método de los materiales reutilizables y sus demostraciones.

## Decisión

Organizar el repositorio en tres áreas principales:

- `methodology/` para los principios y procedimientos;
- `templates/` para formatos que alguien pueda copiar y adaptar;
- `examples/` para mostrar cómo aplicar el método.

El repositorio se creó inicialmente como `cpz-second-brain-framework` y luego fue renombrado a `cpz-theuth-framework`.

## Razones y evidencia

En la conversación del 23-09-2026, el autor confirmó que había creado el repositorio con esas tres carpetas y un README. La separación hace visible la diferencia entre explicar una regla, ofrecer una plantilla y mostrar un caso aplicado.

## Alternativas consideradas

No consta una comparación formal con otras estructuras. Esta organización fue adoptada como una base sencilla para comenzar.

## Consecuencias y condiciones

Los ejemplos deben ser ficticios, anonimizados o estar expresamente identificados como casos reales autorizados. La estructura puede ampliarse si los experimentos revelan una necesidad estable.

## Revisión

- Revisar si aparecen nuevos tipos de contenido que no encajen razonablemente en estas tres áreas.
- Decisión reemplazada: ninguna.
