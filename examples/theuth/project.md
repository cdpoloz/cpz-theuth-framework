# Theuth: methodological framework

- **ID:** project-theuth-framework
- **Status:** active
- **Created:** 2026-09-23
- **Last updated:** 2026-09-29
- **Example type:** authorized real case with an anonymized source; non-canonical

## Purpose

Design a methodology for building persistent, searchable, and maintainable personal knowledge layers. The current project is the methodological framework; the personal implementation is maintained as a separate initiative.

## Current status

The repository contains an initial v0.1 proposal with principles, a knowledge model, a lifecycle, and templates. This folder preserves an illustrative example of project decisions to show how the format is applied; it is not the canonical source for personal records.

When the personal implementation exists, canonical records for this project will be kept in \`knowledge/projects/theuth/\`, with decisions in \`knowledge/projects/theuth/decisions/\`. The reference source for that repository will be confirmation from the responsible person and their work history.
